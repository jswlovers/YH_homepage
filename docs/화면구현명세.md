# YH 화면 구현 명세

- 문서 기준일: 2026-09-27
- 구현 기준: Next.js App Router, React, Tailwind CSS

## 1. 정보 구조

| 화면 | 경로 | 접근 권한 | 구현 위치 |
| --- | --- | --- | --- |
| 포트폴리오 홈 | `/` | 공개 | `src/app/page.tsx` |
| 어시스턴트 로그인 | `/assistant` | 공개 | `src/app/assistant/page.tsx` |
| 어시스턴트 채팅 | `/assistant/chat` | 유효 세션 | `src/app/assistant/chat/page.tsx`, `src/components/ChatUI.tsx` |

공통 헤더와 푸터는 `src/app/layout.tsx`에서 제공됩니다. 모든 화면의 기본 문서 언어는 한국어입니다.

## 2. 화면별 동작

### 홈 `/`

- 중앙 정렬 제목·소개 문구
- `src/lib/designs.ts`의 데이터를 디자인 카드 그리드로 렌더링
- 작품 설명 및 문의 섹션, 이메일 앱을 여는 `mailto:` 링크 제공
- 문의 이메일은 현재 예시값이므로 배포 전 수정 필요

### 개인 비서 로그인 `/assistant`

- 비밀번호 입력 후 `/api/assistant/login`에 POST
- 성공 시 `/assistant/chat`으로 이동, 실패 시 입력 폼 아래 오류 노출
- 처리 중 버튼 비활성화

### 디자인 어시스턴트 `/assistant/chat`

- 보호된 서버 라우트. 세션이 없거나 만료되면 `/assistant`로 이동
- 사용자/어시스턴트 대화를 구분해 표시
- Enter 전송, Shift+Enter 줄바꿈, 요청 중 중복 전송 방지
- 요청 실패 메시지 노출, 로그아웃 API 호출 후 로그인 화면으로 이동
- 채팅 UI 상태는 현재 클라이언트 메모리이며 새로고침 이후 복원되지 않음

### 정책 문서 `/terms`, `/privacy`

- 공개 가능한 서버 렌더링 페이지
- 제목, 개정일, 안내문, 번호가 있는 섹션과 목록으로 구성
- 문서 간 이동 링크와 홈으로 돌아가는 링크 제공
- 모바일에서는 본문을 단일 열로 표시하며 문단 길이에 따라 자연스럽게 줄바꿈
- 법적 효력과 개인정보 고지에 필요한 운영자 정보는 게시 전에 확정

## 3. API 및 데이터 흐름

1. 로그인 UI가 비밀번호를 `/api/assistant/login`으로 전달합니다.
2. 서버는 `ASSISTANT_PASSWORD`와 대조하고 성공 시 7일 유효 HMAC 세션 쿠키를 발급합니다.
3. 보호 라우트는 세션 서명을 검증합니다.
4. 채팅 UI는 전체 대화 배열을 `/api/assistant/chat`에 전달합니다.
5. 서버는 system prompt와 대화 내용을 Anthropic Messages API에 전달하고 텍스트 응답을 반환합니다.
6. 앱의 영속 데이터베이스는 없으며 디자인은 소스 파일, 이미지는 정적 파일로 관리됩니다.

## 4. 스타일 및 반응형

- 중성색 기반, serif 디스플레이 제목과 sans-serif 본문
- Tailwind 유틸리티로 여백, 폭, 그리드, 다크 모드 지정
- 홈 작품 그리드: 모바일 1열, 작은 데스크톱 2열, 넓은 데스크톱 3열
- 채팅 본문 최대 너비 2xl, 로그인 본문 최대 너비 small
- 포커스, 비활성, 오류 상태는 각 입력/버튼의 스타일로 표시

## 5. 메타데이터 및 접근성

- 루트 메타데이터 제목 `YH`, 설명 `패션 디자인 포트폴리오 & 개인 어시스턴트`
- 입력 필드에는 목적을 전달하는 placeholder가 있으나, 장기적으로 명시적 label 연결 권장
- 대화 역할은 정렬과 색상으로 구별되므로 스크린 리더용 역할 텍스트 추가를 후속 개선 항목으로 둠
- 새 정책 페이지는 제목 계층을 유지하고 키보드로 탐색 가능한 Next `Link`를 사용

## 6. 운영 시 수정 지점

- 작품 목록 및 메타정보: `src/lib/designs.ts`
- 공통 푸터 정책 링크: `src/app/layout.tsx`
- 로그인/세션/API 동작: `src/app/api/assistant/`, `src/lib/session.ts`, `src/proxy.ts`
