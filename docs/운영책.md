# YH 서비스 운영책

- 문서 기준일: 2026-09-27
- 대상: YH 디자인 포트폴리오 및 개인 디자인 어시스턴트
- 주요 운영 도구: Next.js 16.3.3, Node.js, Anthropic API

## 1. 서비스 구성

| 기능 | 경로 | 운영상 설명 |
| --- | --- | --- |
| 디자인 포트폴리오 | `/` | 작품 목록과 이메일 문의 링크를 공개 |
| 어시스턴트 로그인 | `/assistant` | 운영자 설정 비밀번호 확인 |
| 어시스턴트 채팅 | `/assistant/chat` | 세션 사용자 전용 UI, Anthropic API 호출 |
| 이용약관 | `/terms` | 서비스 공개 정책 문서 |
| 개인정보처리방침 | `/privacy` | 정보 처리 고지 |

## 2. 환경 및 설정

Node.js 20 이상과 npm을 사용합니다. `.env.local`은 로컬 전용이며 저장소에 커밋하지 않습니다.

필수 환경변수:

```env
ASSISTANT_PASSWORD=강한_비밀번호
ASSISTANT_SESSION_SECRET=충분히_긴_무작위_비밀값
ANTHROPIC_API_KEY=Anthropic_API_키
```

선택 환경변수:

```env
ANTHROPIC_MODEL=claude-sonnet-4-5-20250929
```

키와 비밀번호를 코드, 이슈, 로그에 기록하지 않습니다. 키가 노출되면 해당 제공자 콘솔에서 즉시 폐기·교체하고 배포 환경도 갱신합니다.

## 3. 로컬 실행과 배포

```bash
npm ci
npm run dev
```

배포 전 확인:

```bash
npm run lint
npm run build
```

배포 플랫폼에 필수 환경변수를 등록하고 서버 런타임으로 배포합니다. 정적 내보내기는 로그인 및 API 라우트와 맞지 않습니다. 배포 후 `/`, `/terms`, `/privacy`, `/assistant`를 확인하고, 로그인 성공/실패, 로그아웃, 채팅 응답 및 API 키 오류 동작을 점검합니다.

## 4. 콘텐츠 업데이트

- 작품 데이터: `src/lib/designs.ts`
- 작품 이미지: `public/designs/`
- 문의 이메일: `src/app/page.tsx`의 `CONTACT_EMAIL`
- 약관·개인정보 UI: `src/app/terms/page.tsx`, `src/app/privacy/page.tsx`
- 화면 공통 구조: `src/app/layout.tsx`

문서 원본은 `docs/`의 한국어 문서입니다. 법률 문구를 변경하면 공개 페이지 내용도 함께 맞춥니다. 실제 운영자 연락처 및 국외 이전 관련 필수사항이 확정되기 전에는 법률문서가 완성된 것으로 간주하지 않습니다.

## 5. 보안 및 개인정보 운영

1. 어시스턴트 비밀번호와 세션 서명키는 충분히 강한 값으로 설정하고 주기적으로 점검합니다.
2. 로그인 세션은 HttpOnly 쿠키이며 유효기간은 7일입니다. 로그아웃 시 쿠키 삭제를 확인합니다.
3. 채팅은 브라우저 입력을 서버로 보내 Anthropic API를 호출합니다. 현재 앱은 대화 이력을 영구 저장하지 않지만, 외부 API 및 호스팅 로그 정책은 별도로 확인해야 합니다.
4. 개인정보 문의 및 삭제 요청이 접수되면 요청자 확인 후 처리하고, 법정 보존 의무 여부를 확인합니다.
5. 배포 호스팅의 접근 로그 보존 설정과 Anthropic 계정의 데이터 처리/국외 이전 설정을 기록하고 개인정보처리방침과 일치시킵니다.
6. 공개 이메일의 예시 주소 `your-email@example.com`은 실제 주소로 교체합니다.

## 6. 장애 대응

| 증상 | 우선 점검 | 조치 |
| --- | --- | --- |
| `/assistant/chat`에서 로그인으로 이동 | `ASSISTANT_SESSION_SECRET`, 쿠키, 서버 로그 | 설정 확인 후 서버 재시작, 브라우저 쿠키 점검 |
| 로그인에 실패 | `ASSISTANT_PASSWORD`와 요청 응답 | 배포 환경변수 일치 확인 후 재배포 |
| 채팅 500 응답 | `ANTHROPIC_API_KEY` | 서버 환경변수 등록 상태 확인 |
| 채팅 502 응답 | Anthropic 응답, 모델명, 제공자 상태 | 서버 로그에서 민감값을 제외해 오류 확인, 제공자 상태 확인 |
| 전체 빌드/배포 실패 | 빌드 로그, Node 버전, 잠금 파일 | `npm ci`, `npm run lint`, `npm run build` 순으로 재현 |

API 키나 사용자 입력을 진단 로그에 복사하지 않습니다. 보안 사고가 의심되면 영향을 받는 키와 비밀번호를 교체하고, 배포 플랫폼 로그에서 접근 시점과 영향을 확인한 뒤 필요한 이용자 안내를 진행합니다.

## 7. 정기 점검

- 배포 후 핵심 경로 및 모바일 화면 확인
- 환경변수 접근 권한과 API 사용량 확인
- 디자인 이미지 및 포트폴리오 소개 최신화
- 약관/개인정보처리방침의 시행일, 연락처, 사업자 정보, 처리 위탁·국외 이전 정보 최신화
- 운영 기록과 장애 대응 연락처를 안전한 별도 저장소에 보관
